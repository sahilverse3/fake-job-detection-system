## 📌 Overview

This project is a Java-based application that helps detect fake job and internship postings. It analyzes job details and classifies them as Safe, Suspicious, or Highly Risky.

---

## ❗ Problem Statement

Many students fall into fake job scams where companies ask for money or provide misleading information. There is no easy way to verify job authenticity.

---

## 💡 Solution

This system uses a rule-based approach to evaluate job details such as company name, email, salary, and description to determine risk level.

---

## ⚙️ Features

* Add multiple job entries
* Analyze all jobs
* Classify jobs as Safe / Suspicious / Highly Risky
* Saves data in file (`jobs.txt`)
* Menu-driven interface

---

## 🛠️ Technologies Used

* Java
* OOP (Object-Oriented Programming)
* ArrayList
* File Handling

## ▶️ How to Run
